# Xabi-Geri.repo

Hey, hope you're doing well! This is a lil side project me and my buddy are working on for Loxodon-1 UPRM team. Our goal here was to make a system that takes the most the relevant simulation made in OpenRocket and uploads it into a nice Excel sheet that can be shared among every division making organization more efficient. 

It's very simple and intuitive! 

To keep things simple, have only one person download THE_Tracker.py to their system (ideally the sim guy). Then the sim guy will run a simulation on OpenRocket and export all 58 data points into a .csv file in the same folder they installed THE_Tracker.py

Afterwards, just run the tracker and it'll find the most recent simulation made and create an Excel file named: 'Simulation_tracker_psi_v2'
